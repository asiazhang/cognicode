# C 族判据：文档与知识债（doc-rot / oral-tradition / agent-doc-missing）

> Part of [Wayfinder 地图 #39](https://github.com/asiazhang/cognicode/issues/39) · 来源：[#51](https://github.com/asiazhang/cognicode/issues/51) 判据细则 + [#40](https://github.com/asiazhang/cognicode/issues/40) 类型清单 + [debt-types.md](../../docs/research/debt-types.md)
> 本文件是 C 族分族子代理的完整作业指令。跨族共享约定（证据包 16K 预算、回传 JSON schema、严重度带定档流程）见 [SKILL.md](../SKILL.md)，此处不重复。

> 逐类型人类向详解（含实例）见 [rules/](rules/)：doc-rot · oral-tradition · agent-doc-missing
## 0. 族概览

| slug | 名称 | 证据等级 | 检测档 | rubric 主轴 | 预排 |
|---|---|---|---|---|---|
| `doc-rot` | 文档腐烂（MVP 收窄为注释单通道） | 断链确证 / 语义分叉与过时为风险+置信度 | LLM 为主 | 误导度 | 高 |
| `oral-tradition` | 口头传统 | 全类型风险信号档（存在性候选） | LLM 压测点 | 踩坑概率 | 高 |
| `agent-doc-missing` | 代理上下文文档缺失/撒谎 | 存在性确证 / 过时冲突为风险+置信度 | 确定性（存在性）+ LLM | 误导方向 | 高 |

**检测面聚焦两锚点（MVP）**：文档概念太广，按 agent 触达率只取头部——**代理上下文文档**（第一信源：AGENTS.md / CLAUDE.md / CONTEXT.md 类）+ **代码内注释**（读代码必经）。README / docs/ 长文档信号不设计判据，进雾区（doc-rot 类型留册，长文档信号是类型内信号）。

**两层权威附则（唯一真值延伸）**：已进 CONTEXT.md，裁定时引用——

- **含义类断言**（术语、概念、规则语义）：领域模型文档（代理上下文文档的概念层）若存在则**推定权威**；
- **行为类断言**（可执行事实：命令、路径、函数行为）：**代码为事实**；行为类冲突**只报分叉不裁方向**，方向由人裁。

## 1. doc-rot

### 判据

= **注释断言与代码现实的知识分叉**。只判「说了但说错」，不判漏说（缺失归 oral-tradition / agent-doc-missing）。失败模式：过期书面断言**主动误导** agent（可解性 + 环境可用性）。

MVP 判据收窄为**注释单通道**（#51 决策 1）。

### 三态

| 态 | 检测档 | 证据等级 | 判定 |
|---|---|---|---|
| **断链** | 确定性 | 确证 | 注释提到的符号/路径/命令/配置键不存在 |
| **语义分叉** | LLM | 风险 + 置信度 + **方向未裁** | 对象都在但描述与实现相反；修复建议**双写**（改注释或改代码两方向并列） |
| **单纯过时** | LLM | 风险 + 置信度 | 曾为真值后漂移 |

方向裁定落报告静态标注，MVP 无交互。

## 2. oral-tradition

### 判据

= **应知知识未被 agent 高触达载体（agent 文档 + 注释）覆盖**。关键约定只在人脑里、仓库零痕迹，agent 100% 踩坑且事后无法归因（可解性）。

### 两步法

1. **LLM 生成应知清单**，概念类 / 操作类分层；
2. **比对指定载体**：概念类对照领域模型文档，操作类对照 agent 文档操作层 + 注释。

- 「文档在但没写这条」= 外化缺口特例，记入本类型；概念类缺口另指向 agent-doc-missing 覆盖不足。
- README/docs 低可达知识**接受假阳性**（判据锚定 agent 高触达外化，低可达知识对 agent 仍近似未外化）。

### 显式排除

implicit-contract（痕迹在代码里）与 build-entry-unclear（痕迹在文件系统里）可覆盖的缺口不在本类型（互斥声明，#51 / #53 双向对齐：零文字痕迹场景归 oral-tradition，有痕迹未外化归 implicit-contract）。

### 证据等级

全类型**风险信号档**，报告语言「**存在性候选**」——比 B 族脆性候选再弱一档（连债的存在都是推断）。

## 3. agent-doc-missing

### 三态

| 态 | 检测档 | 证据等级 | 判定 |
|---|---|---|---|
| **存在性** | 确定性 | 确证 | 代理上下文文档清单全缺失；**概念层缺失为置顶档位**（知识的家没建） |
| **过时** | LLM | 风险 + 置信度 | 只扫 agent 文档，判据从严（第一信源误导放大） |
| **冲突** | LLM 为主 | 风险 + 置信度 | 多文档互相矛盾或文档-代码相反；裁定规则 = 两层权威附则 |

多文档并存未声明权威 = **确定性子档**，归冲突态，不开第四态。

### 与 doc-rot 边界（非重叠）

代理上下文文档的三态专属本类型；doc-rot MVP 只走注释通道。

## 4. 留册汇总

| slug/信号 | 为何不覆盖 | 捡回条件 |
|---|---|---|
| `doc-rot` 的 README/docs 长文档信号 | agent 触达率低，检测面聚焦两锚点 | 二期判据票（见地图雾区） |

## 5. 子代理执行协议

- **候选来源**：确定性档 = 注释断链提取（符号/路径/命令/配置键存在性比对）+ 代理上下文文档存在性检查；LLM 档 = 注释语义分叉与过时判定、应知清单生成与比对（oral-tradition）、agent 文档过时/冲突判定。
- **中间产物消费**：本族不消费 test-scan / module-graph；注释通道依赖符号索引做断链比对（symbols 工件若 SKILL.md 提供）。
- **族内分野规则**：doc-rot 只判「说了但说错」（注释单通道）；oral-tradition 只判「该说没说」（应知差集）；agent-doc-missing 只判代理上下文文档三态。三类型零重叠，一实例只挂一 slug，除非多文档冲突同时构成注释分叉（各挂各的）。
- **证据包组装**：断链候选附注释原文 + 目标检索结果；oral-tradition 附应知条目 + 载体检索空白证据；总量 16K 预算内，超预算降采样并在 rationale 声明。
- **输出 schema**：`{slug, location, confidence, rationale, fix_suggestion}` + 提议严重度带。oral-tradition 的 fix_suggestion = 外化建议（写进哪个载体、什么层级）；语义分叉态修复建议双写。
- **rubric 主轴（只锁方向）**：doc-rot = 误导度（行为反转 ＞ 引用断链 ＞ 单纯陈旧）；oral-tradition = 踩坑概率（知识必要性 × 影响面）；agent-doc-missing = 误导方向（撒谎 ＞ 缺失，缺失档内置顶概念层缺失）。注释触达率做信号级标注不进主轴。严重度带只提议不终裁。
