# G 族判据：架构形状债（shallow-module / misplaced-seam / hypothetical-seam）

> Part of [Wayfinder 地图 #39](https://github.com/asiazhang/cognicode/issues/39) · 来源：[#54](https://github.com/asiazhang/cognicode/issues/54) 判据细则 + [#40](https://github.com/asiazhang/cognicode/issues/40) 类型清单 + [debt-types.md](../../docs/research/debt-types.md)
> 本文件是 G 族分族子代理的完整作业指令。跨族共享约定（证据包 16K 预算、回传 JSON schema、严重度带定档流程）见 [SKILL.md](../SKILL.md)，此处不重复。

## 0. 族概览

| slug | 名称 | 证据等级 | 检测档 | rubric 主轴 | 预排 |
|---|---|---|---|---|---|
| `shallow-module` | 浅模块债 | 风险信号 + 置信度 | 确定性（薄壳三元组）+ LLM（穿越成本） | 上下文性价比 | 高 |
| `misplaced-seam` | 错位 seam 债 | 提升度风险 + 泄漏确证子档 | 确定性（提升度 + 泄漏）+ LLM（评估器） | 连带编辑半径 | 中 |
| `hypothetical-seam` | 伪 seam 债 | 风险信号 + 置信度 | 确定性（实现计数）+ LLM（一问定罪） | 假信号误导烈度 | 中 |

**G 族无留册项：三类型 MVP 全覆盖**。传统架构债检测基本靠人审或 CodeScene 行为数据，无商品化竞争；G 族是「防换皮测试」最强的一族。

**证据等级（全族）**：全类型风险信号档，一个确证子档例外——确定性档三类型都只产候选事实（薄壳三元组、提升度清单、单实现计数），判罪靠 LLM 档标置信度；报告语言「架构候选，LLM 判定标置信度」。例外：misplaced-seam 的 **seam 泄漏子档**是确证信号（私有符号被跨模块引用是静态事实不是嫌疑）。

## 1. module-graph 族级共享中间层

G 族三类型共享同一检测底座（术语已进 CONTEXT.md）：

- 模块清单、模块间调用计数、每模块公开/私有符号数（symbols.py 既有资产可产，确定性零 LLM 成本）。
- 模块粒度**粗计数**，不做调用图全图（近调用图分析是重语言相关重活，implicit-contract 砍调用共现锚点时已明确）。
- 新语种 = 新增 token 表，是工程边界不是判据。

**与 E 族 monolith-file 互为镜像（显式分野）**：机制相反（太多薄层 vs 一整个巨物），rubric 共用「上下文」语言但方向相反——monolith 主轴 = 上下文占比高，shallow 主轴 = 性价比低。深目录树本身不是债：每层都真藏行为（每层 deep）时嵌套只是可导航成本。

## 2. shallow-module

### 判据

= **薄壳 + 上下文性价比损失**双因子，缺一不报——高内聚薄层不报，与「高内聚巨文件不报」对称。agent 须穿过多层薄壳才凑出等量行为理解（效率 + 可导航性）。

### 两档分工

- **确定性档**：产薄壳事实三元组（pass-through 比例、接口面宽度、行为量指标），候选线以 **pass-through 比例**为主锚（转发占比高 = 这一层没藏行为，纯中转）。
- **LLM 档**：复用 module_depth.py 判定协议（收集→prompt→单 JSON→重试→丢弃），判「agent 凑出对底层行为的理解需打开几层、每层贡献多少信息增量」，标置信度。

**阈值论证义务**：报实例的依据是「穿越这 N 层花费的读取/推理成本，与把同等行为摊平一层相比的溢价」，逐实例在报告行陈述，不是拍脑袋常数；阈值数值留雾区进技术选型。

### 实例粒度

**模块级**——连续 shallow 模块在报告里相邻呈现并加链标注，不合并实例。

### rubric

主轴 = **上下文性价比**（等量行为理解的穿越成本，越高越严重）；接口面宽度做信号级标注。报告分组 = 效率组（主失败模式），可导航性次归属行内标注。防换皮：传统审查报「分层不严谨」（美学），本类型报穿越成本溢价（失败形态）。

## 3. misplaced-seam

### 判据

= **共编辑提升度 + seam 泄漏**双锚点，两信号可各自或共同触发实例（变更安全性 + 可诊断性）。改一个行为必须跨多模块编辑（无 Locality），agent 改一处漏一片。

### 双锚点

1. **主锚 = git 共编辑提升度**：共编辑是行为的化石记录。确定性档 = `git log --numstat` 按模块分桶，统计模块对**提升度**（lift = P(A∧B) / (P(A)·P(B))），消掉模块活跃度污染；候选线 = lift 超阈 + 最小样本量（如共编辑 < 5 次的对不报）。
2. **副锚 = seam 泄漏**：B 模块的内部/私有符号被 A 跨模块引用（module-graph 公开/私有符号清单可直接判，静态事实，**确证子档**）。

### 两档分工

- **确定性档**：提升度计数全进 + 泄漏判定全进。
- **LLM 档评估器**：判「这对高频共编辑是否共享一个行为」，标置信度；标「设计已锁、实现看样例票成本」。

### 实例粒度

**模块对级**——一对一个实例，两信号挂同一对。

### rubric

主轴 = **连带编辑半径**（改一个行为需波及的模块跨度：跨 2 模块 ＜ 跨 3 层 ＜ 改不动须重设计的焊死）；共编辑频次做信号级标注。报告分组 = 变更安全组，可诊断性次归属行内标注。防换皮：传统审查报「耦合度高」（指标美学），本类型报「agent 改一处漏一片」（失败形态）。

## 4. hypothetical-seam

### 判据

= **单实现抽象 + 假「可换」信号**。agent 在假抽象上浪费推理预算，「可换」是假信号误导规划（效率 + 可导航性）。

### 两档分工

- **确定性档**：口径 = 公开抽象符号 + 实现计数——interface / abstract class / protocol / typeclass / Go interface 的实现类计数（token 表按语种列抽象声明形态）。候选线 = **恰好 1 个实现**；不设存活时间门槛（git 生存期分析进雾区）。确定性档只产「单实现抽象」事实清单，**不判罪**。
- **LLM 档（一问定罪）**：问「仓库语境内是否存在第二条被真实需求驱动的实现路径」，标置信度，**低置信不报**；新生接口豁免由 LLM 档承担。

与 shallow-module 不共用 LLM 判定内容（成本核算 vs 定罪一问），只共用协议骨架。

### 与 shallow-module 边界

单实现抽象常同时是薄壳，同实例**多 slug 并挂**（#49 先例），但主轴与修复建议不同（shallow = 合并/加深，hypothetical = 移除抽象或等第二个实现出现再抽象）。

### 实例粒度

**抽象符号级**——每个单实现抽象一个实例。

### rubric

主轴 = **假信号误导烈度**：多读一层 ＜ 因假接口面放弃直接修改 ＜ 基于换实现假设做出错误方案。实现计数（=1）是收录条件不做排序维度。报告分组 = 效率组，可导航性次归属行内标注。防换皮：传统审查报「过度设计 YAGNI」（品味判断），本类型报无效穿越与错误规划（失败形态）。

## 5. 留册汇总

G 族无留册类型（三类型 MVP 全覆盖；hypothetical 两档全进、shallow 复用 module_depth 协议全进、misplaced 确定性档全进）。

## 6. 子代理执行协议

- **候选来源**：确定性档 = 薄壳三元组（shallow）、git 共编辑提升度 + seam 泄漏清单（misplaced）、单实现抽象计数（hypothetical）；LLM 档 = 穿越成本评估（shallow）、共编辑行为共享评估（misplaced）、定罪一问（hypothetical）。
- **共享中间产物消费（module-graph）**：模块清单 / 调用计数 / 公开私有符号数由 symbols.py 资产产出的 module-graph 工件提供；泄漏判定直接消费其公开/私有清单；新语种 = 新增 token 表（工程边界）。
- **族内分野规则**：shallow 与 hypothetical 常并挂但主轴与修复建议不同（见第 4 节）；shallow 与 E 族 monolith-file 互为镜像不并挂（薄 vs 巨）；misplaced 泄漏子档是全族唯一确证信号。
- **证据包组装**：shallow 附三元组 + 穿越链各层接口摘要；misplaced 附提升度数值 + 泄漏引用点；hypothetical 附抽象声明 + 唯一实现摘要，总量 16K 预算内，超预算降采样并在 rationale 声明。
- **输出 schema**：`{slug, location, confidence, rationale, fix_suggestion}` + 提议严重度带（沿各类型主轴方向提议，不终裁）。
