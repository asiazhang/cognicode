# 静态信号入分：概念维度 × 双测量

CogniCode 绘图时曾锁定「静态分析只做归因与建议驱动，不入总分」，理由是静态打分（DAF 等）缺乏实证校准。票 #4 grilling 中修订了这一前提：AI agent 的实际效果受静态分析结果影响（文档、构建定义等直接改变 agent 行为），静态面必须进入分数才能反映「AI 原生程度」。决定采用「概念维度 × 双测量」结构：每个概念维度可同时携带动态测量与静态测量，维度分由两者聚合，动静互为校验（静态说文档全、动态却检索失败，本身即信号）；总分聚合动态为主体（≥70%），静态为修正项，具体权重留给试点仓库集实证校准——避免重蹈 DAF 无实证权重的覆辙。

## Considered Options

- **仅动态产分，静态纯归因**（原前提）：维度-测量一一对应最干净，但丢掉「agent 效果受静态面影响」的因果事实，且检索/构建两类能力的静态面（文档完备度、构建规范度）本就是强预测信号。
- **静动态维度并列混排**：清单更平，但「可导航性（动态）」与「上下文可发现性（静态）」这类重叠维度会在清单里打架，聚合也更乱。被否。
